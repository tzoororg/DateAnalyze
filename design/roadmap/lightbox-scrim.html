Lightbox caption scrim — current vs proposed

Current = 2-stop rgba(0,0,0,.75) → transparent over 56px. Proposed = 5-stop eased gradient over 88px. Same markup, CSS-only, works over any photo.

Recommendation

Ship the proposed static multi-stop scrim. One-line-ish CSS change to .lb-caption in css/styles.css: taller padding (40→72px top) and the 5-stop eased gradient. Skip JS adaptive sampling — canvas pixel reads on every slide cost CPU, break on CORS-tainted images, and buy nothing this gradient doesn't already give. Keep a lighter text-shadow as backup.
