# Plans

Every design/execution plan for the app, filed by status. **The folder a plan
lives in _is_ its status** — move the file when the status changes.

- `done/` — shipped and live (may still have a manual/setup tail).
- `active/` — being worked now.
- `backlog/` — not started standalone plan docs.

**The index of open work is [`../tracking/BOARD.md`](../tracking/BOARD.md)** —
every active plan appears there as an epic with status, priority, and next step.
Strategy/positioning: [`../ROADMAP.md`](../ROADMAP.md). Shipped history:
[`../tracking/ARCHIVE.md`](../tracking/ARCHIVE.md).
